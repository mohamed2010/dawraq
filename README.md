# 🌸 تطبيق زُهيرة (Zuhaira App) - صحة المرأة والدورة الشهرية (PWA Offline)

تطبيق زُهيرة هو تطبيق ويب تقدمي (PWA) متكامل يعمل 100% **أوفلاين بدون إنترنت** لمتابعة صحة المرأة، الدورة الشهرية، أسابيع الحمل، ونافذة الخصوبة بخصوصية وأمان كاملين.

---

## ✨ أحدث الميزات المدمجة في التطبيق:

1. **إعداد ترحيبي بسيط ولطيف (Onboarding Wizard)**:
   - تخصيص تجربة الاستخدام فور فتح التطبيق لأول مرة.
   - أسئلة دقيقة مخصصة للعازبات والمتزوجات ومتابعة الحمل والتخطيط للحمل.

2. **تسجيل مرن للحيض (الحالي vs القديم)**:
   - **بدء الحيض الحالي**: يطلب تاريخ أول يوم نزف فقط دون إجبار على معرفة تاريخ النهاية سلفاً.
   - **تسجيل دورة قديمة أو مكتملة**: يتيح خيار إدخال تاريخ أول يوم وتاريخ آخر يوم للحساب الدقيق.

3. **حماية وأمان برمز خاص وبصمة الاصبع (Passcode & Biometrics)**:
   - قفل التطبيق برمز PIN خاص مكون من 4 أرقام.
   - دعم الفتح المباشر بـ **بصمة الإصبع / الوجه** على الهواتف المحمولة.

4. **تنبيهات وتوجيهات طبية فسيولوجية (Medical Alerts & Advice)**:
   - شريط تنبيهات تلقائي عند تأخر الدورة أكثر من 7 أيام أو طول الدورة غير الطبيعي.
   - نصائح تغذوية وطبية حية تتغير حسب مرحلة الدورة الفسيولوجية (الحيض، الجرابية، الإباضة، الصفرية).
   - متتبع الأعراض (تقلصات، صداع، انتفاخ) ومُتتبع طبيعة الإفرازات (زلال البيض للإباضة، كريمية، إلخ).

5. **تطبيق ويب تقدمي أوفلاين (PWA & Service Worker)**:
   - حفظ كامل البيانات محلياً على الجهاز لضمان الخصوصية 100%.
   - إمكانية التثبيت كأيقونة تطبيق مستقلة على الشاشة الرئيسية للهاتف.

## 🚀 كيفية رفع التطبيق على GitHub وتفعيله مجاناً (GitHub Pages):

### 1️⃣ الرفع المباشر عبر موقع GitHub (أسهل طريقة):
1. افتحي موقع [GitHub.com](https://github.com) وسجلي الدخول.
2. اضغطي على زر **New Repository** (مستودع جديد).
3. اسمي المستودع: `dawra-app` أو `zuhaira-app`.
4. اتركيه **Public** (عام) واضغطي **Create repository**.
5. اضغطي على خيار **"uploading an existing file"** (رفع ملفات قائمة).
6. قومي بسحب وإسقاط كافة ملفات هذا المجلد:
   - `index.html`
   - `sw.js`
   - `manifest.json`
   - `README.md`
7. اضغطي على زر **Commit changes**.

### 2️⃣ تشغيل التطبيق أونلاين مجاناً (GitHub Pages):
1. داخل المستودع على GitHub، اذهبي إلى **Settings** (الإعدادات).
2. من القائمة الجانبية، اختاري **Pages**.
3. تحت قسم **Build and deployment -> Branch**:
   - اختاري الفرع `main` بدلاً من `None`.
   - اضغطي **Save**.
4. خلال دقيقة واحدة، سيرسل لكِ GitHub رابط تطبيقكِ المباشر يعمل على كافة الهواتف:
   `https://<YOUR-USERNAME>.github.io/dawra-app/`

## 📱 التشغيل المحلي (Localhost):
يمكنكِ تشغيل الخادم المحلي باستخدام Node.js:
```bash
node server.js
```
ثم فتح `http://localhost:8080` في المتصفح.
